# சீன். 10.

இடம்: ரோடு.

நொண்டி வந்தல்.

சிவகுரு, பழனி சந்திப்பு.

நொ : என்ன உலகமடா! கல்லுக்கும் மண்ணுக்கும் கோவில் கட்ட திருப்பணி. என்போன்ற ஏழைக்குத் திருப்பணி செய்ய யாருமில்லை, என்ன மடமை மிகுந்த நாடு.

(பாட்டு) போதல்

(நண்பர் குழாம் வருதல்)

சிவ : கணபதி, எங்கேடா போறே?

கண : ஆபீசுக்கு போறேன்.

சிவ : உனக்கு விஷயம் தெரியுமாடா?

கண : என்னப்பா அது?

சிவ : நம்ப அழகப்பன் சிக்கா இருக்கானும். போய்ட்டு வரலாம்.

கண : நான் வரலே. ஆபீசுக்கு டைம் ஆச்சி.

சிவ : டேய் ஜம்பு! நீயாவது வாரியா?

ஜம் : போப்பா. அன்னைக்கு ஒரு கிளாஸ் கேட்டதற்கு அரை கிளாஸ் கொடுத்தான். அவனைப் பார்க்கிறதா? நான் போரம்ப்பா.

(இவர்கள் பழனியப்பன் பார்த்துக்கொண்டிருத்தல்)

சிவ : அடே, நன்றிகெட்ட பசங்களா! யாரப்பா நீ? என்னையே பார்த்துக்கிட்டே இருக்கே.

பழனி : நான் அழகப்பன் வீட்டுக்கு விருந்தாளியாக வந்திருக்கேன். என்பெயர் பழனியப்பன்.

சிவ : ஓ! நீதான் பழனியப்பன் என்பவனா?

பழனி : ஆமாம்.

சிவ : ஆமாம். அழகப்பன் செத்துட்டானா? இல்லை. பிழைச்சிட்டானா?

பழனி : பிழைக்கமாட்டான்.

சிவ : ஏன்?

பழனி : எல்லாம் மதுவின் திருவிளையாடல்.

சிவ : என்ன! மதுவுக்குக்கூட ஒரு திருவிளையாடல் உண்டா?

பழனி : ஆம். மது! மது! இந்த உலகை நிலை கலக்கியதே அது!

சிவ : மது! மது! ஆஹா! இந்த உலகை நிலை கலக்கியதே அது!

# சீன். 16.

இடம்: மணியப்பன் வீடு.

மணி : என்ன இந்தக் கருப்பனே வரச் சொன்னு, இன்னும் வரலே. (கருப்பன் வருகிறான்.)

கரு : கும்பிடுங்க!

மணி : டேய், யாரடா கும்பிட சொல்ற?

கரு : இல்லிங்க, கும்பிடுறேன்னு சொல்றேன்.

மணி : இதுதான் மரியாதையா? ஆள் வந்ததாடா உனக்கு?

கரு : ஆள் வந்தாங்க. குடிச்ச கஞ்சியை அப்படியே போட்டுட்டு வந்துட்டேன். என்னுங்க சமாச்சாரம்?

மணி : பழனியப்பனை உனக்குத் தெரியுமாடா?

கரு : பக்தி உள்ள கடவுளாங்க? எல்லாம் சொல்லுங்க. நான் போன தில்லிங்க!

மணி : அத சொல்லலேடா. என் மகன் பழனிடா.

கரு : ஓகோ அவரா! பொதுக்கூட்டம் போட்டுக்கிட்டு கள்ளு குடிக்காதே சாராயம் குடிக்காதேன்னு, பள்ளன் வீட்டிலே சாப்பிடு, பறையன் வீட்டிலே கையலம்புன்னு சொல்றாரே அவரா?

மணி : அவன் தாண்டா.

கரு : அவருக்கு எங்க இந்த ஊர் வம்பு?

மணி : ஊர் வம்பு மாத்திரம் அல்லேடா. என் வீட்டு வரைக்கும் வந்துட்டாண்டா.

கரு : சே! சே! இம்மாதிரி வம்பு பண்ணினு நல்ல தும்பா போட்டு கட்டனுமங்க.

மணி : ஏண்டா! நம்ப சாந்தாவை உனக்குத் தெரியுமாடா?

கரு : எனக்குத் தெரியாதுங்களே.

மணி : அரியலூர்லே கட்டிக்கொடுத்து அறுத்துட்டு வந்தாளே, அவள் தாண்டா!

கரு : ஓ! நல்லா தெரியுமே! அவங்களுக்கு என்ன?

மணி : ஒண்ணுமில்லேடா. அவளுக்கு மறு விவாகம் செய்து கொடுக்கணுமாம்!

கரு : என்ன, விதவைக் கல்யாணமா? என்னுங்க சீதை, பாஞ்சாலி, திரெளபதை, நளாயினி இவங்க பிறந்த நாட்டிலே விதவைக் கல்யாணமா? அதுகடக்குதுங்க.

மணி : பழனியை கடுமையாக இரண்டு வார்த்தை. திட்டிவிட்டேன். அதனாலே வீட்டைவிட்டு வெளியே போய்விட்டான். அவனே நீதான் வீட்டுக்கு அழைத்துவர வேண்டும்.

கரு : நான் கூப்பிட்டா வரப்போறாரு?

மணி : டேய், ஒருகால் ... மூதேவி! நீ போய் கூப்பிடவேண்டாம்டா. இந்தச் சங்கத்துப் பக்கம் தலை காட்டினு தலையே போய்விடும்னு பயம் காட்டு. அவன் திருந்திவிடுவான் என்ன யோசிக்கிறாய்.

கரு : யோசனை ஒண்ணுமில்லை. கள்ளுத்தண்ணிக்குக் கூட காசில்லை. மாமா வீட்டுக்குப் போய்ட்டு வரலாம்னு பார்த்தேன்.

மணி : பணம் வேணும்னு கேளண்டா. (பணம் கொடுத்தல்) டேய் பணத்தைக் கண்டபடி பண்ணுமே கள்ளு சாராயம் வாங்குடா.

கரு : பணம் இருக்குடுங்க பணம். மனுஷாள் தான் வேணும்.

மணி : சரிதாண்டா. பணத்தை வாங்கின உடனே இப்படி பேசறியோ. டேய் முக்கியமா உங்கிட்ட ஒண்ணு சொல்லணும். அதாவது காரியத்தை ரகசியமாக முடிக்கணும்.

கரு : என்னுங்க மீன் குஞ்சுக்கு நீந்தக் கத்துக் கொடுக்கறீங்க. எல்லாம் நான் பாத்துக்கிறேன்.

மணி : போடா (போதல்) சாந்தா!

கரு : ஏம்பா.

மணி : கொஞ்சம் காப்பி கொண்டுவாம்மா.

(கொண்டுவரல்)

மணி : ஏம்மா சாந்தா! அண்ணன் தான் இப்படி ஊறிகிட்டு இருக்கானு, நீயுமா இப்படி கெட்டுவிட்டாய்?

சாந் : அப்படி ஒண்ணும் கெடெல்லியே.

மணி : கெடவில்லையா! கெடாமல்தான் மறுவிவாகம் செய்துகொள்ளப் பிரியப்படுகிறாயா?

சாந் : புருஷன் செத்துப்போன பொண்டாட்டியும் கூட விழுந்து சாவாங்க. என்னவோ பேசரியே, அப்பா! அம்மா இறந்தபோது தாங்கள்கூட விழுந்து சாகத் துணிந்தீர்களா? இரண்டாந்தாரம் கல்யாணத்திற்குக்கூட முயற்சி செய்தீர்கள்.

மணி : சீ, கழுதை! யாரிடம் இந்த வார்த்தையை பேசுகிறாய்?

சாந் : என் தந்தையிடம் பேசுகிறேன். என் உரிமைகளைக் கேட்கின்றேன். இதில் என்னப்பா குற்றம்?

மணி : உன் தந்தையிடம் பேசும் வார்த்தையா இது? நாட்டில் மழை இல்லை என்றால், எப்படிப் பெய்யும்? விபசாரிகள் பெருத்து விட்டால் நாசகாலம்தானே!

சாந் : அப்பா! அண்ணாவின் கொள்கையோ விபசாரத்தை ஒழிப்பது. தங்களுடைய கொள்கை விபசாரத்தை வளர்ப்பது. தாங்கள் மாத்திரம் என்ன, தங்களுடைய மதமே விபசாரத்தை வளர்ப்பதுதானே!

மணி : சீ, கழுதை! சாந்தா! என் சொல்படி கேட்டுக் கொண்டு இருக்க இஷ்டமிருந்தால் இரு, இல்லாவிட்டால் எவனையாவது இழுத்துக்கொண்டு ஓடிவிடு. விபசாரி! விபசாரி! விபசாரி! (போதல்)

(தனிப்பேச்சு)

சாந் : பாவி! நானு விபச்சாரி! நானு விபச்சாரி! என் உள்ளக் கிடக்கைகளை ஒளிக்காமல் சொன்னேன். அது விபச்சாரம்! எத்தனையோ விதவைகளின் உள்ளத்திலே துடித்துக்கொண்டிருக்கும் எண்ணத்தை வாய்விட்டுச் சொன்னேன். அது விபச்சாரம்! எது விபச்சாரம்? கணவனை இழந்தவர்கள் கண்ணீரும் கம்பலையுமாக நிற்பது விபசாரமா? நீ மனைவியை இழந்தாயே, உனக்கு ஏன் நெற்றியில் பொட்டு? நீ மனைவியை இழந்தாயே, உனக்கு ஏன் வித விதமான வாசனைத் திரவியங்கள்? நீ மனைவியை இழந்தாயே, உனக்கு ஏன் உல்லாச வாழ்க்கை? உணர்ச்சி உனக்கு மட்டும்தானா இருக்கிறது? உனக்கு மட்டும்தானா உரிமை? பெண்களைக் கண்டதும் பல்லை இளிக்கிறதே அது விபசார வாழ்வு அல்லவா? நான் செய்தது விபசாரமா? நீ செய்தது விபசாரமா? எது விபசாரம்? மன நிலையை அறிந்துக்கொள்ள முடியாத மடமையே! அழிந்து படு! நான் தேடின கணவனை என்னிடமிருந்து பிரித்தாயே, அதுவே விபசாரமல்லவா? என் வாழ்வை வெட்டிப் பிரித்த வேற்றுமைப் பிசாசே! அழிந்து போ! ஒழிந்து படு! எது விபசாரம்? எது விபசாரம்?

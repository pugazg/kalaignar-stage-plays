# சீன். 17.

இடம் : ரோடு

(அய்யர் கருப்பன் சந்திப்பு)

கரு : என்ன சாமி, இப்பதான் போறீங்களா?

அய் : ஐயையோ! சத்தம் போடாதே. மானத்தை வாங்கிடுவேபோலிருக்கே. ஆமாம், சாராயக் கடையிலே யாரு இருக்கா?

கரு : ஒருத்தரும் இல்ல. சீக்கிரமா போங்க.

(அய்யர் போதல்)

என் சாமி, நானும் வரட்டுமா?

அய் : இனனைக்கு வரும்படி ரொம்ப குறைச்சல்.

கரு : என்ன சாமி, எப்பப் பாத்தாலும் சீட்டெல்லாம் ஆடுறீங்க. இல்லென்னு சொல்றீங்கோ.

அய் : அதெல்லாம் சொல்றத்துக்கு இதுதானு இடம்? ஆமாம். இப்போ எங்கே போறே?

கரு : உங்க விரோதி ஒருத்தன் இருக்கான் பாருங்கோ. அவனுக்குப் புத்தி கொடுக்கப் போறேன்.

அய் : ஒருத்தன் என்ன. உலகமேதான் எனக்கு விரோதி. அது யாரு என் விரோதி?

கரு : அடே, அவன் தான் சாமி! மணியப்ப முதலியார் மகன் பழனியப்பன் இல்லெ. அவனை அடிக்கும்படி அவனுடைய அப்பா பணம் கொடுத்திருக்காரு.

அய் : மணியப்ப முதலியார் அப்படி சொன்னாரா? பேஷ். இதையும் வச்சுக்கோ. (பணம் கொடுத்தல்). இனி அவனை உதைக்கிற உதையிலே அவன் இருக்கானு செத்தானுனு இருக்கணும்.

கரு : அதையெல்லாம் நான் பாத்துக்கிறேன். நீங்க போங்க சாமி.

அய் : அதாவது நான் பணம் கொடுத்து அவனை அப்படிச் செய்யச் சொன்னேன் என்று யாரிடமும் சொல்லாதே.

கரு : என்னுங்க. நீங்க கள்ளுக்குடிக்கிறதையே ஒருத்தர் கிட்டேயும் சொல்லலே.

அய் : ஐயையோ இதையெல்லாம் தெருவிலே இருந்துகிட்டா சொல்றது. நீ.... போடா! (ஐயர் போதல்)

கரு : டேய் பழனி! இந்த கருப்பங்கிட்டேவா நடக்கும்? (பாட்டு—சீன் முடிவு)

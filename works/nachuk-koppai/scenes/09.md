# சீன். 9.

இடம் : மணியப்ப முதலியார் வீடு

(அய்யர் வருகை)

மணி : என்னது, சாந்தாவீட்டிலிருந்து தபாலா கிபாலா ஒண்ணும் காணோம். ஒன்றும் புரியலையே!

(அய்யர் வரல்)

அய் : என்ன முதலியார்வாள்! வெளியே புறப்பட்டாப்போல இருக்கு.

மணி : ஆமாஞ்சாமி! நம்பள மறந்திட்டீங்களா என்ன?

அய் : என்ன முதலியார்வாள்! இவ்வளவு சுலபமா சொல்லிட்டீரே. எப்படி தங்களை மறக்க முடியும்?

மணி : ஆமாம். இப்போ எங்கே வந்தீங்க?

அய் : காரியம் இல்லாமலா வருவேன்.

மணி : அப்ப என்ன விஷயம்?

அய் : இம். இருக்கு.

மணி : என்ன விஷயம்! சொல்லுங்கோ?

அய் : அதாவது ராதா கல்யாணம் வர்றது.

மணி : யாருக்கு? தங்கள் மகளுக்கா?

அய் : சே! சே? என்னென்னு... இப்படிக் கேட்டேள். இவ்வளவு பக்திமானாக இருந்தும். நீரும் உம் மகனுட சேர்ந்துட்டயோ?

மணி : யாராவது சொல்றதை கேக்றது. அதைக் கொண்டுதான் எனக்கு எல்லாம் தெரியும்.

அய் : அதாவது ராதாவுக்கும் கிருஷ்ணனுக்கும் போன யுகத்தில் நடந்த ஐதீகத்தை இப்பொழுது உற்சவமாக நடத்துறோம். அதுதான் ராதா கல்யாணம்.

மணி : அதுக்கு நான் என்ன சாமி செய்யணும்?

அய் : ஏதோ ஒரு தொகை கொடுத்து உதவினும் தங்களுக்கு பகவத் கிருபை கிட்டும். அதுவுமல்லாமல் சுடகோடி சூர்ய நாராயண அய்யர் கதா காலக்ஷேபமும் இருக்கு. நீங்களும் அவசியம் வரணும்.

மணி : அடேடே! என்ன சாமி! நான் வராமலா இருப்பேன். (பணம் கொடுத்தல்)

அய் : ஆமாம். மூணு மரக்கா பச்சரிசி வேணும்.

மணி : ஏன் சாமி?

அய் : பகவானுக்குத் துத்திவண்ணம் செய்யணும்.

மணி : சாமி, நெல்லு அடிக்கலிங்க. அடுத்த மாசம் தான் அடிக்கணும்- அடிச்சன்னு கொடுத்தனுப்புறேன்.

அய் : அடுத்த மாசம் கொடுத்து ஆகற காரியமில்ல. அப்படியின்னு எங்க ஆத்ல உள்ள அரிசியை எடுத்து செய்றேன். பிறகு நீங்க கொடுத்திடுங்கோ.

மணி : அப்ப சரி. போயிட்டு வாங்க.

அய் : வரும்போது உங்காத்திலேயே சாப்பிட்டு வந்துடுங்கோ.

மணி : ஏன் சாமி?

அய் : அங்கே பிராமணனுக்குத்தான் போடணும். சூத்ராளுக்குக் கிடையாது.

மணி : சாப்பாட்டுக்கு என்ன குறைச்சல் சாமி! பகவான் கிருபையாலும் தங்களுடைய ஆசீர் வாதத்தினாலும் நிறைய இருக்கிறது.

அய் : அப்ப சரி. நான் வர்றேன்.

மணி : போயிட்டு வாங்க.

(அய்யர் போதல். நொண்டி வருகை. பாட்டு)

நொண் : ஐயா!

மணி : யாரடா நீ?

நொ. காலையிலிருந்து பட்டினி ஐயா!

ம : யாரடா என்று கேட்டால், பட்டினி ஓலை வாசிக்க வந்து விட்டாயே! யாரடா நீ?

நொ : ஐயா! நான் ஒரு நொண்டி! பிச்சைக்காரன். வயிற்றுக்கு இல்லை. ஏதாவது கருணை செய்ய வேண்டும்.

ம : ஏண்டா வர்றவன் போறவனுக்கு எல்லாம் சத்திரமா கட்டிவைச்சிருக்கேன். போடா வந்தவழியே.

நொ : அதிகமான பசி ஐயா!

ம : போகிறாயா! உதைக்கட்டுமா?

நொ : போய் விடு என்றால் போகிறேன். உதைக்க வேண்டாம்.

ம : பிச்சை எடுக்கிற கழுதைக்குப்பேச்சு வேறு? மரியாதையாகப் போகமாட்டாய்.

நொ : அய்யனே! நீர் ஒரு பெரிய தர்மகர்த்தா என்று கேள்விப்பட்டு வந்தேன். இங்கு அதர்மம் தலை விரித்தாடுவது எனக்குத் தெரியாது. நஞ்சுக்கு அமிர்தம் என்று பெயரிட்டிருப்பதை நான் அறியேன்.

ம : தர்மத்தைப் பத்தி ரொம்ப தெரிஞ்ச கழுதை! போடா.

நொ : திமிரான் பேச்சு! இது உமது குற்றமல்ல. உமது பண்படாத அறிவின் குற்றம். சிந்தனை என்ற வயலுக்கு ஆராய்ச்சி என்ற நீர் பாய்ச்சும். பகுத்தறிவுப் பரம்படித்து, உயர்வு தாழ்வு என்ற மேடுபள்ளங்களைச் சமப்படுத்தி மூட மதி என்ற களைகளை முற்றிலும் அகற்றும். விவேகம் என்ற விளைவு ஏற்படும். அப்பொழுது தெரியும். தர்மம் எது அதர்மம் எது என்று. நல்ல எண்ணம் என்பது நமக்குக் கடவுளாக இருக்கையில் கோவில் ஏன்? உழைக்கக் கை கால்கள் இருக்கையில் ஊரார் சொத்தை உறிஞ்சுபவனுக்கு இலவச போஜனம் ஏன்?

மணி : டேய்! என்னடா நினைச்சி பேசற! கொஞ்சம் கூட மரியாதை தெரியல. ஒரு பிச்சைக்காரப் பயல் என்ன என்னடா பேசறது. உதைச்சிடுவேன். உதைச்சி பிச்சிடுவேன் பிச்சு. என்னடா பெரிய வேஷம் எல்லாம் போடுறே.

நொ : ஐயா! நானு வேஷம் போடுகிறேன். நானு காவி யணிந்து காமியாக வாழ்கிறேன். நீறு பூசி நீச்சத் தன்மையையா வளர்க்கிறேன். என் உள்ளத்திலெழும் அலைகளே என் உதடுகளின் அசைவாய் இருக்கிறது. வயிறு கேட்டதையே வாய் கூறுகிறது. இதுவா வேஷம்? நன்று! நீர் வேஷம் போடுகிறவனை அறியவில்லை போலும்! அதிலே கிடந்து சொக்குகிறீர். என் போன்ற ஏழைமக்களிடம் கடு மொழிகளைக் கக்குகிறீர். இனியாவது உண்மையை உணரும். அறிவு உலகம் உமக்கு வழிகாட்டுமாக.

(பாட்டு. போதல்)

மணி : இந்த அயோக்கியப் பயல் என்னவோ பேசிட்டுப் போயிட்டான் கடவுளே.

(பழனி வருகை)

பழனி : எல்லாம் அவன் செய்த அயோக்கியத்தனம் தான்.

மணி : என்னடா? அயோக்கியத்தனம்?

பழனி : வேறென்ன? பாட்டாளியையும் பணக்காரனையும் படைத்தது அவன் செயல்தானே? உழைப்பாளியையும் உண்டு களிப்பவனையும் உண்டு பண்ணியது உயரிய செயல் என்பது உமது கருத்தா? பஞ்சத்தால் பாட்டாளி வாடவும், மஞ்சத்தில் பணக்காரன் மதுர கீதம் பாடவும் ஆன நிலையை உண்டு பண்ணியது உமது ஆண்டவனின் செயல் அல்லவா? கோவில் கும்பாபிஷேகத்திற்கு 5000- ரூபாய்! பிராமண போஜனத்திற்கு 10000 ரூபாய்! இதற்கெல்லாம் பணத்தை வாரி இறைத்திடுறீரே, இடிந்து விழும் குடிசையிலே மடிந்துபோகும் பாட்டாளியைக் காப்பாற்ற மது செல்வம் பயன்பட்டதா- பரலோகம் கிடைக்கும் என்ற கனவைத் தவிர?

மணி : ஏ தம்பி! நமக்கு ஏண்டா இந்த ஊர் வம்பு? நல்ல பிள்ளையின்னு பேர் எடுடா!

பழனி : அப்பா!

மணி : ஏண்டாப்பா.!

பழனி : நான் நல்ல பிள்ளைன்னு பேர் எடுக்க விரும்பவில்லை. பகல் வேடக்காரனிடம் பட்டம் வாங்கவும் எனக்குப் பிடித்தமில்லை. என் அறிவுக்கும் ஆற்றலுக்கும் எது நல்லது என்று படுகிறதோ அதை நான் செய்தே முடிப்பேன். தயங்கவும் மாட்டேன். என்னைக் கண்டு இந்தச் சமுதாயம் பல்லைக் கடிக்கிறது. அது பல்லைக்காட்டும் நாள் அண்மையில் வருகிறது. அப்பா! என்னைக் கேளாமல் சாந்தாவை அழகப்பனுக்கு அளித்தீரே, அவள் எழுதி இருக்கும் கடிதத்தைப் பாரும்.

மணி : என்னடா எழுதி இருக்காள்? கடுதாசி வந்திருக்கா? படி, படி. கேட்போம்.

பழனி : (படித்தல்) அன்புள்ள அண்ணா! வணக்கம், நான் இவ்விடம் சுகமாகத்தான் இருக்கிறேன். என் வாழ்வில் வளமையைப் பெருக்கவேண்டிய வயதில் வளைவை ஏற்படுத்திவிட்டார் தந்தை. எனக்கு அமைந்த கணவர் நல்லவர் என்று நினைத்துச் சிறிது நாள் மகிழ்ந்திருந்தேன் கடைசியாக வெறுக்கப்பட்டேன். என் கணவர் குடிகாரர்-குடித்தனக்காரரல்ல! மதுவின் மடியில் கிடந்ததால் இப்போது அவருக்குப் பெருநோய் பிடித்துவிட்டது. பிழைக்க முடியாத ஆபத்து. விடுதலையில்லா விபத்து. எத்தனை தொல்லைகள் வந்தாலும் பொறுமையாக நட என்பது அப்பாவின் பொன் மொழியாக இருக்கலாம். ஆனால், நளாயினி காலமல்ல இது. உடனே பதில். இப்படிக்கு சாந்தா.

மணி : நீதான் படித்துவிட்டு வர்ணனை வேலை செய்கிறாய் என நினைத்தேன். சாந்தாவும் தேவலைபோலிருக்கே ஆமாம். நீ என்னடா பதில் எழுத?

பழனி : உங்கள் நெஞ்சம் என்ன இரும்பு நெஞ்சமா? நான் என்ன பதில் எழுதுவது? மணியப்ப முதலியார் மகன் ஒரு உணர்ச்சியற்ற மரக்கட்டையாக வாழ்கிறான் என்ற பதிலைத்தான் எழுதமுடியும், பணம்...பணம்....பணம். அவளைக் கெடுத்தது.

மணி : இது எங்கே பிழைக்கப்போகுது. ஊம். என்னவோ நான் இரண்டு மூணு காசு சேர்த்து வைச்சிருக்கேன். இது என்னன்ன உரைதச்சுப் போட்டுக்கிட்டு அலையுது. கடவுளே!

தந்தி பியூன் : மணியப்ப முதலியார் இருக்காரா?

மணி : இந்தா மரம்போல இருக்கேனே! என்ன சமாச்சாரம்?

பி : டெலகிராம் வந்திருக்கு.

மணி : என்ன கிராம்?

பி : தந்தி.

மணி : தந்தியா! கொடுங்கோ. இது என்னவோ இங்கிலிஷில் எழுதி இருக்கே.

பி : ஒரு கையெழுத்துப் போடுங்கோ. பேனா கொண்டு வாங்கோ.

மணி : வாங்க இருக்கு என்னையா இது. வீட்டில் உள்ளவங்கதான் இப்படியின்னு வர்றவங்கோ போறவங்கல்லாமே இப்படியா இருக்கணும்.

பி : கோபிக்காதீங்க. சரி. நான் வர்றேன்.

மணி : சரி. போய்வாங்க.

பி : சில்லறை...

மணி : எத்தனை ரூபாய்க்கி?

பி : காப்பி குடிக்க.

மணி : அப்படியா! அதோ தெரியுது இல்ல கடை. அங்கேபோய் காசு கொடுத்துட்டு சாப்பிட்டுப் போங்கோ.

பி : உங்களை கேக்கறேன்னு?

மணி : என்னை கேட்டிங்களா. நாளை வாங்க. சரி. வர்றவங்கோ போறவங்கோ எல்லாம் காசுன்னு பிடுங்குறாங்கோ. நான் என்ன காசு காக்கிற மரமா? இனி யாருவரட்டும் ஒரு சிங்கல் பை கொடுப்பேனோ. காசு கழுவற, தண்ணி? இந்த மணியப்ப முதலியைப் பார்த்தா எல்லோருக்கும் இளக்கமா போச்சு. இருக்கட்டும். தம்பி! இது என்ன புரியலையே. டேய் பழனி! இங்கே வாடா. இதைப் படி.

பழனி : அழகப்பனிடமிருந்து வந்திருக்கிறது.

மணி : என்னடா வர்றோம்னு எழுதி இருக்காங்களா?

பழனி : (தலையை அசைத்தல்)

மணி : என்னடா உனக்குப் புரியலையா? ஏண்டா இதுக்கா நான் உன்னைப் பணம் செலவு பண்ணி படிக்க வைச்சேன்.

பழனி : அழகப்பன் டேஞ்சர். ஸ்டார்ட் இமிடியட்.

மணி : என்னடா. தாட்டுப் பூட்டுங்கறே. ஒண்ணும் புரியலையே. தமிழில் சொல்லா?

பழனி : அழகப்பனுக்கு அதிக ஆபத்து நேர்ந்து விட்டதாம். உடனே வரச்சொல்லி இருக்காங்கோ.

மணி : சரி. புறப்படுங்கோ. ஐயோ! இந்தக் கால பலமே சரியில்லை. என்ன என்ன வரப்போகுதோ கடவுளே!

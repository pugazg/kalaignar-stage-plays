# சீன். 18.

இடம் : பகுத்தறிவு மன்றம்

[பழனி, சிவகு.]

(பழனி வாட்டமாயிருத்தல்.)

(பாட்டு)

சிவ : தோழா! நேற்று நீ கூறியபடி கம்பராமாயணத்தையும் பெரிய புராணத்தையும் ஆதியோடு அந்த மாப் புரட்டிப் பார்த்தேன்.

பழனி : அதிலென்ன முடிவு கண்டாய் தோழா?

சிவ : முடிவு ஏது தோழா. அதில் ஒரு கவிதை தோன்றியது சொல்லட்டுமா?

பழனி : சொல்லேன். கேட்கலாம்.

சிவ : நக்கிக் குடிக்கின்றார் நம் புலவர் கலை ரசத்தை! சொக்கித் துதிபாடும் சோதாவே! புரட்டிப் பார். ஆபாசத்தை அழுகுத் தட்டில் ஊற்றி பாயாசம் என்றுரைத்தால் பருகுவரோ பண்டிதர். கம்பரும், கிழாரும் நம்மருந் தமிழ் நாட்டில் வெம்பிய கலை வகுத்தார்கள். கருத்துக்குக் கலையா? கட்டுப்பாட்டுக்குக் கலையா? வெறுத்து ஒதுக்கும் காலமே! நீ! வேகமாய் வா! எப்படிக் கவிதை?

பழனி : ஆஹா! கவிதை என்ன அழகாய் இருக்கிறது? அதுவும் பாரதிதாசன் பிறந்தநாடல்லவா!

சிவ : ஆம் தோழா! 'கம்பன் வீட்டுக் கட்டுத் தறியும் கவி பாடும்' என்பார்கள் முன்னோர்கள். ஆனால் 'பாரதிதாசன் வீட்டுப் பானை சட்டியும் பண்ணமைக்கும்' என்பது இன்றைய தமிழகத்தின் திருமொழி தோழா!

பழனி :—சிவகுரு, நீ வீட்டுக்குப் போகவில்லை?

சிவ :—நண்பா!... இன்னுமா வாட்டமாயிருக்கிறாய்?

பழனி :—பிரியப் போகும் திராவிடத்தை நான் காண முடியாதே என்ற வாட்டந்தான்!

சிவ :—நீயே இப்படிப் பேசுவதா?

பழனி : நானே ஒரு தங்கையை வீட்டிலே வெம்ப வைத்துவிட்டு வைதிகம் சீற, அவளது விழிகளில் நீர் சோர, விதவை என்று வீணர் கூற அதை நான் பார்த்துக் கொண்டு, சும்மா இருப்பதா? நீயே இப்படிப் பேசுவதா?

சிவ : உன் தந்தைக்குப் பிறகு உன் தங்கைக்குத் திருமணம் செய்து கொண்டால்...?

பழனி : இப்போதே என் தங்கையைக் கொலை செய்து விட்டு நானும் தற்கொலை செய்து கொள்கிறேன். பிறகாவது சாந்தாவை ஏகாம்பரத்திடம் ஒப்படைக்கிறாயா?

சிவ : தோழா! நீ ஆத்திரத்தில் பேசுகிறாய். நாயின் வாலை நிமிர்க்க முடியுமா?

பழனி : நிமிரா விட்டால் வெட்டி எறிவது, தோழா!

சிவ : நிம்மதியாகப் படுத்துறங்கு. நாளை காலை பேசிக் கொள்ளலாம். நான் வருகிறேன்.

(சிவகுரு போதல்)

(பழனி ஒரு கோப்பையில் நஞ்சைக் கலக்கிறான்.)

(கடிதம் எழுதுதல்)

பாழும் சமூகத்தின் பழிகாரத் தந்தையே! சாந்தாவின் வாழ்வைப் பல வழியிலும் கெடுத்தீர். அவளை விதவையாக்கினீர். அவளை நாசமாக்கினீர். ஏகாம்பரம் என் தங்கையை ஏற்றுக்கொள்க. நான் விட்டுப்போன வேலையைச் செய்துமுடி. சாந்தா! நீ ஏகாம்பரத்திடம் மன்னிப்புக் கேள். திராவிட உலகமே! தன் மானம் பெறு. சாந்தாவின் எண்ணத்தைப் பண்படுத்தாத நான் இருந்தென்ன? இறந்தென்ன? நான் சாகிறேன்.

இப்படிக்கு,

பழனியப்பன்.

பழனி : (விஷத்தை வைத்துக் கொண்டு.) அப்பா! என்னைக் கெடுத்தீர். சாந்தாவின் வாழ்வையும் சிதைத்தீர். இதோ சாகிறேன். உம் மனம் குளிரட்டும். செத்துப் போன சமூகம் சிரித்து மகிழட்டும். சாந்தா! உன் பொருட்டு என் உயிரைக் கத்தரித்துக் கொள்கிறேன்.

(இதைப் பேசிக் கொண்டே அங்குள்ள அறிஞர் அண்ணாவின் படத்தைப் பார்க்கிறான். மனம் குழம்புகிறது)

அண்ணா! திராவிடத் தளபதி! தற்கொலை செய்து கொள்வது கோழையின் செயல் என்கிறீர்களா? வீரனுக்கு அழகா என்கிறீர்களா? செயலாற்ற முடியாத கோழையே என்கிறீர்களா? ஆம். அன்று முதல் நான் ஒரு சீர்திருத்தக்காரன், இன்று முதல் சாந்தா ஒரு சீர்திருத்தக்காரி, என்றும் ஏகாம்பரன் ஒரு சீர்திருத்தக்காரன்.

இந்த மூன்று சீர்திருத்தக்காரர்களும் மதத் திமிர் பிடித்த மடையர்களுக்கு அடங்கித்தான் நடக்க வேண்டுமா? பணமும் பதவியும் என்ன செய்ய முடியும்? உணர்வை ஒழிக்க முடியுமா? அல்லது தங்களுடைய கொள்கையைக் கொளுத்த முடியுமா? முடியாது. ஏ பணமே! மதமே! பார்க்கிறோம் உங்களை ஒருகை.

(நச்சுக் கோப்பையைக் கீழே வீசி உடைக்கிறான்)

(கருப்பன் வருகை)

கரு : டேய், யாருடா சத்தம் போடறது?

பழனி : யாரப்பா நீ?

கரு : நீ யாருன்னு கேட்டா, என்னையே திருப்பிக் கேக்கறே. டேய், சங்கத்திலே உனக்கு என்னடா வேலை? சங்கம், கிங்கம்னு பேசுனியே உன்னைப் பங்கப் படுத்திடுவேன். இந்தச் சிங்கத்தைத் தெரியுமாடா?

பழனி : ஏய், மரியாதையாக வெளியே போகமாட்டாய்.

கரு : டேய் தம்பி, உன்னை வெரட்ட வந்திருக்கேன்டா நான். என்னவோ சொல்வாங்களே ஒண்டவந்த பிடாரி ஊர்ப் பிடாரியை ஓட்டுவேன் என்றதாம்.

பழனி : போடா குடிகாரப்பயலே.

கரு : டேய். என்னையா குடிகாரங்கிறே! நீயா? நானாடா?

பழனி : சீ, கழுதை! வெளியே போடா. (இருவரும் கை கலந்து சண்டையிடுதல். பழனியைக் கருப்பன் கத்தியால் குத்தி விடுகிறான்.)

உள்ளதைச் சொன்னால் உறுமலா? ஆராய்ச்சி என்றால் ஆத்திரமா? கடமையை உணறு என்றால் கத்திக்குத்தா? நிலையை நினைத்திடு என்றால் கொலையா? ஆ! அப்பா!

(இறத்தல்)

(விடிந்து போலீஸ் வருதல்.)

தெலுங்கு போலீஸ் : இவள ஏமோ கொலை ஸின்னுஉண்டதே ஏது ஏமி?

(கத்தியை எடுத்தல்)

அடே பழனியப்பன் கொடுக்கு மணியப்ப முதலியார். மணியப்ப முதலி கொடுக்கு பழனியப்பன் காது. எவரோ சேசின பணி.

(ஊதலை எடுத்து ஊதல்)

மலையாள போலீஸ் : எந்தா! எதுக்கு விலிச்சி.

தெ. போ : கேசவ நாயர். குடு.

ம. போ : எந்தா சொலா.

தெ. போ : எந்தா. கேசவ நாயர். இந்த ஆள்வார் நாயிடு ஒக்கவாரமா வீட்டிலே லேது. ஏமி கலாட்டா, ஏமி பணி, ஏமி ஜகடம், ஏமி கேசவ நாயர். போயி ஜெமாகாயில் கண்ரா.

ம. போ : ஊரும் நீ போம் விலுச்சினுவா. பயமா இருக்கு.

தெ. போ : அப்போ நீ இக்கடே உந்து, நான் போயிட்டு பாத்துன்னு.

ம. போ : எனக்கு பயமாயிதே. நீ போத்தாலு.

தெ. போ : மனசு லேயும் ஆக வயித்திலேயும் ஆச்சு சீக்கிரம் ராண்டி.

(திருடல்)

(சப்-இன்ஸ்பெக்டர் வரல்)

சப். இன்ஸ் : ஏய் 208! என்னடா இது?

தெ. போ : கொலை சார்.

சப். இன்ஸ் : எப்படியடா ஆச்சு?

தெ. போ : தெல்லேதே சார்

சப். இன்ஸ் : எதுக்கடா இருக்கே நீ?

தெ. போ. : ஏமிட்டிலேது.

சப் இன்ஸ். : ரிகார்டு பார்த்தல்.

தெ. போ. சார்.

சப். இன்ஸ் : (கடிதம் வாசித்தல்.)

சரிதான். பழனியப்பன் தற்கொலை செய்திருக்கணும். ஏய் 104 போய் மணியப்ப முதலியாரை அழைத்து வா.

(104 போதல்)

சப். இன்ஸ் : எங்கடா?

ம. போ. : நான்.

சப். இன்ஸ் : என்னடா சொல்றே?

ம. போ. : ......

சப். இன்ஸ் : இவன் என்னடா. இவனைக் கேட்டால் மலையாளம், அவனைக் கேட்டால் தெலுங்கு, உங்களைக் கட்டிகிட்டு மாரடிக்க வேண்டியிருக்கே.

தெ. போ. : அவுனு.

சப். இன்ஸ் : சுத்தப் பைத்தியமா இருக்கே.

ம. போ.: அதே அதே. மணியப்ப முதலியாருக்கும் அதே! அதே!

சப். இன்ஸ்: ஏ. சி. 2081 நீ இனிமே வேலைக்கு லாயிக் இல்லே.

தெ. பொ: எந்துக்கு சார்.

சப் இன்ஸ்.: உனக்கு வயிறு ரொம்ப பெருத்து விட்டது.

தெ. பொ.: அவுனு.

சப் இன்ஸ்.: அதனாலே தேவையில்லே.

தெ. பொ.: ஏமி சார் போனஸ்?

சப் இன்ஸ் : பெல்ட் எங்கே?

தெ. போ.: வயிற்றுக்குப்பத்தலே.

சப் இன்ஸ்.: டைரி கொடு.

(சிவகுரு வருதல்.)

(சிவகுரு கடிதத்தைப் பார்த்து

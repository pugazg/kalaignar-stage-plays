# சீன்.2

இடம் : மணியப்ப முதலியார் வீடு.

(அய்யர், பழனியப்பன், சாந்தா வருகை)

அப்பனே, முருகா, ஷண்முகா, வேலாயுதம், கந்த வேல் பெருமானே.

மணி : என்ன,இன்னைக்கு வெய்யில் இவ்வளவு கடுமையாக அடிக்கிறது? அந்த அய்யரை வேறே வரச் சொன்னேன். இன்னும் வரலே. அந்த மனுஷன் எப்போதுமே அப்படித்தான். ஏதோ நல்ல காரியத்துக்கு வரச் சொன்னா, இன்னும் வரலையே. சரி, வெளியே தெருவரையாவது போய்ட்டு வரலாம்.

(அய்யர் வருகை)

அய் : என்ன முதலியார்வாள்! எங்கே புறப்பட்டேள்?

மணி : வாங்க! உங்களுக்கு ஆயுசு நூறு!

அய்: எமன் இளிச்சவாயனா யிருந்தால்...!

மணி: என்னவோ வந்திட்டிங்க-கும்பிடப்போன தெய்வம் குறுக்கே வந்தது மாதிரி!

அய் : ஆமாம். நீங்க கூப்பிட்டதாக வீட்டுக்கு ஆள் வந்தான்னு ஆத்திலே சொன்னா. அப்போதான் காரமடைக்கு ஒருகருமாதிக்குப்போய்ட்டு வந்தேன், காலையில் வரலாமனு நினைத்தேன். அதுக்குள்ளேயும் நம்ப லக்ஷமணன் தாத்தா செத்துட்டான்னு கருமாந்திரம் செய்யணும்னு ஆள் வந்தான். அதையும் முடிச்சுட்டு சற்று ஓய்வா வந்தேன். அதுல கூட பாருங்கோ,ஒரு நாமகரணத்துக்கும் கர்ணபூஷணத்துக்கும் என் மகனை அனுப்பிச்சிட்டு வந்தேன்னா, வரும்படி இருக்கட்டும்னா, தங்களைப்போல மனுஷாள் தானே வேண்டும்!

மணி : ஆமாம்,சாமி! நான் கூட ரொம்ப நாழியா உங்களைப் பார்த்துட்டு நம்ப புண்ணிய மூர்த்தி அய்யருக்குச் சொல்லி, அனுப்பிச்சேன். அவரு பிராமண போஜனத்துக்குப் போய்ட்டாருன்னு திரும்பி வந்துட்டான். சரின்னு நானும் பேசரமல் இருந்துட்டேன்.

அய் : அதிருக்கட்டும்! எதற்காக என்னைக் கூப்பிட்டேள்?

மணி : நம்ப பொண்ணு சாந்தா சாதகத்தைப் பார்க்கணும். அதுக்குத் தான் கூப்பிட்டேன்.

அய் : அவ்வளவுதானே! வேறொன்றும் இல்லையே?

மணி : ஏய்! யார்ரா அது...? அந்த வெற்றிலைப் பெட்டியை எடுத்துவாடா!

அய் : வேண்டான்னா. நான் போடுற பழக்கமில்லை. சரி, சாதகத்தை எடுத்துட்டு வாங்கோ.

(மணி: உள்ளே போய்ச் சாதகத்தைக் கொண்டுவரல)

மணி : ஏன் சாமி!பொடி போட்டிங்களா என்ன.?

அய் : ஆமாம்!

மணி : பொடி என்ன மிளகாய்ப் பொடி வாசனையா இருக்கு.

அய்: கடையிலே விக்கிற பொடி காரம் போர்றது இல்லை. அதனாலே மிளகாய்ப் பொடியே அரைச்சி நானே கலந்து கொண்டேன். (சாதகத்தை அய்யர் பார்த்தல்)

அய்: என்ன முதலியார்வாள்! கண்ணாடிகொண்டு வாங்க.

மணி : சாமி! அது தான் பொட்டெல்லாம் சரியா இருக்கிறதே.எதுக்குக் கண்ணாடி?

அய் : அடே! முகம் பார்க்கற கண்ணாடி அல்ல. மூக்குக் கண்ணாடியைக் கேட்டேன்.

மணி : மூக்குக் கண்ணாடியா நான் போட்ர பழக்கமில்லை. சும்மா பாருங்க.

(அய்யர் சாதகத்தைப் பார்த்தல்.பழனி வரல்.)

பழ: என்ன சோதிடர்வாள்! காற்று இந்தப் பக்கம் அடிக்கிறதே. என்ன விசேஷம்?

அய் : இல்லே. குழந்தே கல்யாண விஷயமா வரச் சொன்னா.

பழ : அப்பா ! கல்யாணமா ...! யாருக்கு?

மணி : என்னடா இப்படிக்கேட்கிறே ? நம்ப சாந்தாவுக்குத்தான்.

பழ : சாந்தாவுக்கா? சாந்தாவை யாருக்குக் கொடுக்கப் போகிறீர்கள்?

மணி : அரியலூர் அழகப்பனுக்கு.

பழ : என்ன! அழகப்பனுக்கா! அப்பா! அழகப்பன் சம்மதிக்கலாம். நீங்களும் சம்மதிக்கலாம். ஜோசியரும், அவர் கூறும் முப்பத்து முக்கோடி தேவர்களும், நாற்பத்தெண்ணாயிரம் ரிஷிகளும் நவக்கிரகங்களும் சம்மதிக்கலாம் ஆனால், சாந்தாவின் சம்மதம் வேண்டாமா?

மணி : ஏய் பழனி! சாந்தா என் மகள்.

பழ: என் தங்கை என்பதை நினைப்பூட்டுகிறேன்.

மணி : அவள் எனக்கு அடிமை.

பழ: அன்பிற்கு! அதிகாரத்திற்கல்ல!

மணி : இங்கு அகராதி படிக்க வேண்டாம்.

பழ: அப்படிதான் தோன்றும்.

மணி: தகப்பனை எதிர்த்துப் பேசும் தறுதலையே !

பழ: நிலமை அப்படி,

அய்: அப்பா பழனி! தகப்பனார் வார்த்தையைக் கேள். பெரியவாள் சொல்வதைத் தடுக்காதே.

பழ : அய்யர்! இது எங்கள் வீட்டு விஷயம். இதிலும் நீர் தலையிட வேண்டாம்.

அய் : சரிதான் அப்பா.

மணி : டேய் பழனி! உனக்கு இந்தக் கலியாணத்திற்கு இஷ்டமில்லையானால் நீயும் சாந்தாவும் வீட்டை விட்டு வெளியே போங்கள்.

பழ : அப்பா ! இதுதான் உங்கள் அன்போ? சாந்தா சந்தோஷ வாழ்வு வாழ விரும்புகிறாள். தனக்குப் பிடித்த மணவாளனைத் தேடுகிறாள். என்றைக்குச் சாந்தாவின் எண்ணம் எதிர்காலத்தின் மீது பாய்ந்ததோ அன்றைக்கே எதிர்வீட்டு ஏகாம்பரத்தின்மீது அவளது விழிகள் பாய்ந்துவிட்டன. இதை நான் சொல்லவில்லை. சாந்தாவின் வார்த்தையை உம்மிடம் சொல்லுகிறேன், அப்பா!

மணி : பழனி என்ன வாழ்வு- புடலங்காய்! வர்ணிக்க ஆரம்பித்து விட்டாயே. சாந்தாவை இப்பொழுது கிணற்றிலா தள்ளப் போகிறேன்?

பழ : கிணற்றில் மட்டும் தள்ளவில்லை அப்பா. அவள் தலையில் கல்லையும் தூக்கிப் போடப் போகிறீர்கள். நான் சொல்வதைக் கேளுங்கள். சாந்தாவுக்குப் பிடித்த மணவாளனுக்கே மாலை சூடச் சொல்லுங்கள்.

மணி : ஏய் பழனி! யாரிடம் இந்த வார்த்தை பேசுகிறாய்! காதலாம்! அன்பாம்! வாழ்வாம்! ஏகாம்பரத்தைப் பற்றி எனக்கு அப்பொழுதே தெரியுமே. அவர்கள் பார்த்துக்கொண்ட பார்வையும், ஜாடையும் தெரிந்து தானடா கலியாணத்திற்கு இவ்வளவு துரிதப்படுத்தினேன். கேவலம், ஒரு வெற்றிலை பாக்குக் கடைக்காரனுக்கா என் மகளைக் கொடுப்பேன்? அதிலும் ஏழ்மையிலே நெளியும் ஏகாம்பரமா சாந்தாவுக்குக் கணவன் ? உண்மையிலேயே உனக்கு பயித்தியம் தானடா பிடித்திருக்கிறது.

பழ: அப்பா!காதல் ஏழ்மையை எண்ணிப் பார்ப்பதா? எதிர்ப்புக்கு அஞ்சுவதா? அன்பிற்கு மாத்திரம் தானே அது அடிமை!

மணி: மறுபடியும் அதையே பேசுகிறாயே. உனக்குச் சம்மதம் இல்லையானால் நானாவது வீட்டை விட்டுப் போகிறேன். நீயாவது ஆட்சியை நடத்துபோ.

பழ : கருங்கல்லைக் கரைக்க முடியுமா? கட்டாந்தரையில் பயிரிட முடியுமா? கண்ணில்லாதவனுக்கு மண்ணில் உள்ள காட்சிகளைக் காட்ட முடியுமா? முடியாது. ஆட்சியை இனி நீண்டநாள் நடத்த முடியாது. அதற்கு அழிவுகாலம் அண்மையில் வந்துவிட்டது. லாயத்திலே தள்ளி அடைக்கப்படும் குதிரைக்குக்கூடச் சிறிது களைத்திட உத்தரவு உண்டு. அதுகூட இல்லையே இந்த நாட்டுப் பெண்களுக்கு ! இந்த நாட்டைப் பூகம்பம் அழிக்காதா? புகையும் எரிமலையும் பொங்கி வழியாதா? அப்பா! நீங்கள் சாந்தாவின் வாழ்வைப் பலியிடுகிறீர்கள் என்பதை மாத்திரம் மறந்துவிடாதீர்கள். அதன் விளைவு பிறகு விபரீதமாக முடியும். இதுவே எனது வேண்டுகோள்.

(பழனி உள்ளே போதல்)

மணி : சாமி!பார்த்திங்களா?

அய்: பார்த்தேன்.நான்மட்டுமா பார்க்கிறேன்? நீங்களும் சேர்ந்துதானே பார்க்கிறேள்!

மணி : பார்த்தீங்களா? அப்போ பாருங்கோ. ஏன் சாமி, இந்தமாதிரி அநியாயம் எந்த வீட்டிலே நடக்கும்?

அய் : எங்கன்னா நடக்கும்- தங்கள் வீட்டைத் தவிர. இப்படித் தண்ணி தெளிச்சி விடக்கூடாது உங்க பிள்ளைகளை. சாஸ்திரம் சொல்லுது. "வேதாளம் சேருமே வெள்ளெருக்குப் பூக்குமே - பாதாள மூலி படருமே - பிராமண துவேஷி மனை" என்று வள்ளுவனே குறள்ல பாடிட்டான்

மணி : ஏன் சாமி! இம்மாதிரி நடந்தால் என் மானம் எங்கசாமி போறது.

அய் : கப்பல் ஏறி பயணம் போக வேண்டியது தான்.

மணி : சரிதான். உங்களுக்குத் தெரிஞ்சா இந்த உலகத்துக்கே தெரிஞ்ச மாதிரிதான்

அய் : சே,சே, என்னை அப்படி நினைக்கிறேளே...!

மணி: என்ன,போ, சாமி நாலு கோண எழுத்து படிச்சுட்டுதுனா காதலும் கத்தரிக்காயும் பேசுது.' இதல்லாம் படிக்கவச்சது நம்ப பிசகு பாருங்க.

அய் : அடே,சரிதான்னு விடுங்கோன்னா. இந்தக் காலத்துப் பிள்ளையாண்டான்களே இப்படித்தான். ஏதோ ஒரு கிரகக் கோளாறு இப்படி பேசுறானுங்க. எல்லாம் இன்னும் கொஞ்ச நாள் போனா சரியாப் போயிடும்.

மணி: இப்ப அவனுக்கு கிரகங்களோ? அப்போ அவனை விடாது. ஒரு சுத்து சுத்தித்தான் விடும். அது இருக்கட்டும் சாதகத்தைப் பாருங்கோ.

அய் : ஆமாம்.எனக்கு நாழியாயிடுத்து. ஆமாம், மாப்பிள்ளை ஆத்து ஜாதகம் இருக்கோன்னோ?

மணி : இல்லை சாமி! அவுங்க கொடுத்தனுப்பல்லே. பேர் ராசிக்கே பாருங்கோ

அய்: மாப்பிள்ளை பேரு என்ன?

மணி : அழகப்பன். பெண் பெயர் சாந்தா.

அய்: அழகப்பன் - சாந்தா, சாந்தா - அழகப்பன் ! ஆஹா! ஹா ! எவ்வளவு பொருத்தமான பேரு ! பேரு பொருத்தமே இவ்வளவு அழகாயிருக்கும்போது வேறு பொருத்தம் எதற்கு முதலியார்வாள?... அதாவது பரம சிவனுக்கும் பார்வதிக்கும், மகாவிஷ்ணுக்கும் லக்ஷ்மிக்கும், சரஸ்வதிக்கும் பிரம்மாவுக்கும் கூட இவ்வளவு பொருத்தமா அமையலேன்னா !

மணி : என்னமோ சாமி, நான் யாருக்கும் ஒரு கெடுதியும் செய்தது இல்லை. பகவான் என்பக்கம்தான் இருந்து வருகிறார்.

பயப்படவேண்டாம்.

அய் : நீங்க ஒன்றுக்கும் இனிமேதான் உமக்கு நல்லகாலம். நான் வீட்டைவிட்டுப் புறப்படும்போதே கருடன் வட்டம் இட்டது. அதிலே எனக்குப் பரம திருப்தின்னா.

மணி : கருட சகுனம் கைகண்ட சகுனம்னு சொல்லுவாங்களே. சரி சாமி, ஒரு நல்ல நாளா பாருங்கோ. கல்யாணம் சீக்கிரம் ஆகணும்.

அய் : முதலியார்வாள்! திங்கள் கிழமை சோமவாரம் 5½ - மணிக்கு மேல்பட்டு 6½ - மணிக்குள்ளாக முடித்துவிட்டால் நல்லது.

மணி : சாமி, நீங்க சொல்லும்போதே கவுளி சொல்லுது. அந்த நாள் எனக்குப் பிடிக்கல்லே.

அய் : வேறே நாள் வைக்கலாம். எனக்கு வேறொரு இடத்திலே ஒரு கருமாதிக்குப் போகணும்.

மணி : சாமி! என்னது? என் வீட்டில் வந்து உட்கார்ந்துகொண்டு கருமாதிக்கும் கல்லெடுப்புக்கும் சாதகம் பார்க்கிறிங்க

அய் : நான் எதுக்கு சொல்றேன்னா, ஒத்துக்கொண்ட நாள் போக, பாக்கி நாளில்தானே ஒத்துக்கொள்ளணும். அதனாலே தான் சொல்றேன்.

மணி: அப்படியா! அப்பேர் உங்க இஷ்டத்துக்கே செய்ங்க சாமி.

அய் : சரி, நாழியாயிடுத்து. நான் போகணும். உங்காத்து வேலைக்காரனே நம்ப ஆத்துப் பக்கம் கொஞ்சம் வரச் சொல்லுங்கோ. கல்யாணத்துக்கு வேண்டிய சாமான்களை எல்லாம் எழுதி அனுப்புகிறேன்.

மணி : அப்போ சரி சாமி! பணம் கொடுத்து

அய் : (சிரித்து) இதுக்கு இப்ப என்ன அவசரம்?

மணி : அப்ப சரி.

அய் : அடடே, அதுக்குள்ளே, போடுங்கன்னா பர்சிலே கொண்டு வைக்கிறேளே. (பணம் கொடுத்தல்)

அய் : நான் போய்ட்டு வர்றேன்.

மணி : சரி சாமி.

(சாந்தா பள்ளியிலிருந்து வரல்)

மணி : அம்மா சாந்தா! பள்ளிக்கூடம் போய்ட்டு வரியா அம்மா?

சாந்: ஆமாம்பா.

மணி : எல்லாம் படிச்சி முடிச்சிட்டியா அம்மா?

சாந் : இன்னும் கொஞ்சம் இருக்கு அப்பா.

மணி: படிச்சது போதும். இனி பள்ளிக்கூடம் போக வேண்டாம்.

சாந்: ஏன் அப்பா?

மணி : உனக்குக் கல்யாணத்திற்கு ஏற்பாடாகி விட்டது.

சாந்: எனக்கு எதுக்கு அப்பா இப்பக் கல்யாணம்?

மணி: என்னம்மா இப்படிப் பேசறே.விளையாட்டுத் தன்மா வயசு 18 ஆகிவிட்டது.

சாந் : அப்பா! இதை என்னைக் கேட்டுக்கொண்டா செய்யவேண்டும்?

மணி : வேறே யாரம்மா கேட்கிறது?

சாந்: என்னை யாருக்குக் கொடுக்கிறீர்கள்?

மணி : அரியலூர் அழகப்பனுக்குத்தான்!

சாந் : அப்பா! ஒருவன் வாயிலே விஷத்தைப் பலாத்காரமாகத் திணித்துவிட்டு அதைச் சாப்பிடுவதைப் பற்றிய அபிப்ராயத்தை அவனிடம் கேட்பதுபோல் இருக்கிறது, தங்களுடைய பேச்சு!

மணி : இதென்ன எழவு எடுத்த ஏழவா இருக்கு. வீட்டிலேயே படுத்துத் தூங்குகிறாயே.ஏதாவது ஒரு நல்ல இடத்தைப் பார்த்துக் கல்யாணத்தை முடிச்சுவைக்கலாமனா, என்னவோ வேதாந்தம் பேசுகிறாயே.

சாந் : அப்பா! நான் ஏன் உங்களிடம் ஒளிக்க வேண்டும். என் உள்ளத்தை ஏகாம்பரத்திடமே ஒப்படைத்து விட்டேன். இனி அதைப் பிரிப்பது என்பது அறுசுவைச் சாப்பாட்டைவிட்டு ஐயரைப் பிரிப்பதுபோல் ஆகும்.

மணி : நீ வெற்றி பெற்று விடுவாய் என்ற எண்ணத்தால் கிண்டல் வேறு செய்கிறாய். நீ செத்தாலும் சரி. ஏகாம்பரத்தை ஒருகாலும் மணக்க முடியாது!

சாந்: அப்படியானால் என் சவத்திற்குத் திருமணம் செய்து வையுங்கள்.

மணி: இந்தப் பூச்சாண்டி எல்லாம் என்னிடம் காட்ட வேண்டாம்.

சாந்: அப்பா! மனத்திற்கேற்ற மணவாளன்....!

மணி : அதைத்தான் மாற்றிக்கொள்ள வேண்டும் என்று சொல்கிறேன்.

சாந்: காரணம்?

மணி: காரணமா? ஒன்றல்ல, இரண்டல்ல, ஒரு ஆயிரம் காரணங்கள் சொல்ல முடியும்.ஏன் சாந்தா, அழகப்பனைவிட ஏகாம்பரம் எந்த வகையில் உயர்ந்தவன்? அய்யரை ஏசி ஏசி ஒரு சல்லிக்கு வழி இல்லாமல் செய்திட்டான் .இன்னைக்கெல்லாம் இருந்தால் ஒரே ஒரு வெற்றிலை பாக்குக் கடைதான். அழகப்பனை மணந்து கொண்டால் பணத்திலேயே கிடந்து பொரளலாம். காரை விட்டுக் கீழே இறங்கவேண்டியதில்லை. அவன் காலால் இட்ட வேலையைத்தலையால்செய்ய எத்தனையோபேர்காத்துகிட்டு இருக்கிறாங்க. ஏகாம்பரத்தை மணந்தால் ஒன்னுக்கு இரண்டு பத்திரவத்துக்கு மூணா நீயும் போகவேண்டியது தான். நான் சொல்வதைக் கேளம்மா.என்னம்மா பேசாமே நிக்கறேயே. உன்னிஷ்டந்தான் சொல்லேன்.

சாந்: சரி அப்பா ! உங்கள் இஷ்டம்போல் செய்யுங்கோ.

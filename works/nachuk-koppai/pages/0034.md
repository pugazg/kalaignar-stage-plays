# நச்சுக்கோப்பை

சீன். 9.

இடம் : மணியப்ப முதலியார் வீடு

(அய்யர் வருகை)

மணி : என்னது, சாந்தாவீட்டிலிருந்து தபாலா கிபாலா ஒண்ணும் காணோம். ஒன்றும் புரியலையே!

(அய்யர் வரல்)

அய் : என்ன முதலியார்வாள்! வெளியே புறப்பட்டாப்போல இருக்கு.

மணி : ஆமாஞ்சாமி! நம்பள மறந்திட்டீங்களா என்ன?

அய் : என்ன முதலியார்வாள்! இவ்வளவு சுலபமா சொல்லிட்டீரே. எப்படி தங்களை மறக்க முடியும்?

மணி : ஆமாம். இப்போ எங்கே வந்தீங்க?

அய் : காரியம் இல்லாமலா வருவேன்.

மணி : அப்ப என்ன விஷயம்?

அய் : இம். இருக்கு.

மணி : என்ன விஷயம்! சொல்லுங்கோ?

அய் : அதாவது ராதா கல்யாணம் வர்றது.

மணி : யாருக்கு? தங்கள் மகளுக்கா?

அய் : சே! சே? என்னென்னு... இப்படிக் கேட்டேள். இவ்வளவு பக்திமானாக இருந்தும். நீரும் உம் மகனுட சேர்ந்துட்டயோ?

மணி : யாராவது சொல்றதை கேக்றது. அதைக் கொண்டுதான் எனக்கு எல்லாம் தெரியும்.

அய் : அதாவது ராதாவுக்கும் கிருஷ்ணனுக்கும் போன யுகத்தில் நடந்த ஐதீகத்தை இப்பொழுது உற்சவமாக நடத்துறோம். அதுதான் ராதா கல்யாணம்.

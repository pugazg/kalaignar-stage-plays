மு. கருணாநிதி

மணி : அதுக்கு நான் என்ன சாமி செய்யணும்?

அய் : ஏதோ ஒரு தொகை கொடுத்து உதவினும் தங்களுக்கு பகவத் கிருபை கிட்டும். அதுவுமல்லாமல் சுடகோடி சூர்ய நாராயண அய்யர் கதா காலக்ஷேபமும் இருக்கு. நீங்களும் அவசியம் வரணும்.

மணி : அடேடே! என்ன சாமி! நான் வராமலா இருப்பேன். (பணம் கொடுத்தல்)

அய் : ஆமாம். மூணு மரக்கா பச்சரிசி வேணும்.

மணி : ஏன் சாமி?

அய் : பகவானுக்குத் துத்திவண்ணம் செய்யணும்.

மணி : சாமி, நெல்லு அடிக்கலிங்க. அடுத்த மாசம் தான் அடிக்கணும்- அடிச்சன்னு கொடுத்தனுப்புறேன்.

அய் : அடுத்த மாசம் கொடுத்து ஆகற காரியமில்ல. அப்படியின்னு எங்க ஆத்ல உள்ள அரிசியை எடுத்து செய்றேன். பிறகு நீங்க கொடுத்திடுங்கோ.

மணி : அப்ப சரி. போயிட்டு வாங்க.

அய் : வரும்போது உங்காத்திலேயே சாப்பிட்டு வந்துடுங்கோ.

மணி : ஏன் சாமி?

அய் : அங்கே பிராமணனுக்குத்தான் போடணும். சூத்ராளுக்குக் கிடையாது.

மணி : சாப்பாட்டுக்கு என்ன குறைச்சல் சாமி! பகவான் கிருபையாலும் தங்களுடைய ஆசீர் வாதத்தினாலும் நிறைய இருக்கிறது.

அய் : அப்ப சரி. நான் வர்றேன்.

மணி : போயிட்டு வாங்க.

(அய்யர் போதல். நொண்டி வருகை. பாட்டு)

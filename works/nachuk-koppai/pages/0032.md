# நச்சுக்கோப்பை

சீன். 8.

இடம் : ரோடு

(சின்னையா பிள்ளை, கன்னையா செட்டி வருகை)

சின் : ஏனப்பா பழனி, எங்கே போகிறாய்?

பழனி : இன்று ஒரு பொதுக்கூட்டம். அதில் பேச வேண்டும். அதற்காகப் போகிறேன்.

சின் : சாமியைப் பழித்துத்தானே பேசப்போகிறீர்கள்?

பழனி : சாமியைப் பழிக்கிற கயவர்களைப்பற்றிப் பேசப் போகிறேன். ஆமாம், நீங்கள் எங்கே போகிறீர்கள்?

சின் : நாளைக்கு என் பொண்ணுக்குக் கலியாணம். மழை பெய்யக்கூடாதுன்னு பிள்ளையாருக்கு ஒரு தேங்காய் உடைச்சிட்டு வரலாம்னு போறேன்.

பழனி : அப்போ, செய்யுங்கோ.

(கன்னையா வருகை)

பழனி : என்ன! கன்னையா செட்டியவர்களே, எங்கே இவ்வளவு தூரம்?

கன் : மழையில்லாமே நிலமெல்லாம் வறண்டு விட்டது. நாளைக்கினாலும் மழை பெய்யட்டுமின்னு மாரியம்மனுக்கு ஒரு தேங்காய் உடைக்கப்போகிறேன்.

பழனி : சின்னையா பிள்ளையவர்களே! கன்னையா செட்டி கூறிய வார்த்தைகளைக் கேட்டீரா? நீர் உமது மகளுடைய கல்யாணத்துக்கு மழைபெய்யக் கூடாதுன்னு தேங்காய் உடைக்கப்போகிறீர். அவர் நிலம் வறண்டுவிட்டது. மழை பெய்ய வேண்டுமென்பதற்காகத் தேங்காய் உடைக்கப்போகிறார். இதில் கடவுள் யாருக்கு அனுக்கிரகம் செய்வார்?

சின் : ஏன்? நல்லவாளுக்குச் செய்யட்டுமே!

கன் : அப்படியின்னு நான் கெட்டவனா?

## காட்சி—3.

(சந்தை வெளியிலே சாக்ரடீஸ் பேசிக்கொண்டிருக்கிறான்.)

சாக் : சந்தையிலே பொருள் வாங்கும்....விந்தை மனிதர்காள்! அங்கெல்லாம் கிடைக்காத அரும்பொருள், நானொன்று வைத்திருக்கிறேன். விலை மதிக்கவொண்ணா வைரம்! ஆராய்ச்சி என்னும் ஆழ்கடலில் குளித்தெடுக்கும் ஒளி முத்து! அங்காடிக் கடையிலே அகப்படாத பொருள்! அறிவு! அறிவு! இந்த அதிமதுரப் பொருளை வாங்க வாரீர்! வாரீர்!

(கிரேக்கத்துச் சிப்பாய் வருகிறான்.)

சிப்பாய் : நிறுத்து உன் பிர சங்கத்தை!........

சாக் : நான் நிறுத்தினாலும் அதைத் தொடர்ந்து நடத்த என் தோழர்கள் பலர் இருக்கிறார்களே!

சிப் : தெகிடுதத்தம் பேசாதே! நீ வாலிபர்களைக் கெடுக்கிறாய்; நடுத்தெருவில் பைத்தியம்போல் புலம்புகிறாய்!

சாக் : உன்னை, என்னிடம் அனுப்பியவர்களிடம் போய்ச்சொல்.... ஆடு மேய்ந்து அழிந்துவிடும் அருகம்புல் அல்ல, புத்துலகு சமைப்போரின் போதனை என்பதை! கருத்தொளி காட்டுக் குதிரையல்ல தம்பி, அதிகாரக் கடிவாளமிட்டதும் அடங்கி ஒடுங்கிவிட!....

சிப் : அதிகப்பிரசங்கியாரே! உமது பேச்சை நாளை நீதிமன்றம் கேட்கட்டும்! வாரும் என்னோடு, இப்போது!

(இழுக்கிறான், சாக்ரடீசை)

கிரி : இது என்ன அக்கிரமம்! எங்கு இழுத்துச் செல்கிறாய், தள்ளாத வயதில்....எங்கள் அறிவுத் தங்கத்தை — விடு வீரனே, விடு!....

சாக் : வேண்டாம் நண்பனே, வேண்டாம் ...! நான் எங்கே போகிறேன்?நீதிமன்றத்திற்குத்தானே! கொலைக்களத்திற்கு அல்லவே!....என்னைப் போகவிடு! கருத்திலே தெளிவும் கொள்கையிலே வலிவும் இருக்கும்வரை விசாரணைக்கும் வழக்கிற்கும் விவேகிகள் பயப்படத் தேவையில்லை. போகிறேன். அறிவுப்பாதை காட்டுவோரை அழிவுப்பாதைக்கு விரட்டும் அநியாயக்காரர்களை நேரடியாகச் சந்தித்துப் போர் தொடுக்கப் போகிறேன்.

(சிப்பாய், சாக்ரடீசை இழுத்துச் செல்கிறான்.)

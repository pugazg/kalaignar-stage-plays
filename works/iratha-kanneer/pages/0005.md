# முன்னுரை

இரத்தக் கண்ணீர் தழுவல் ஓவியம். ஆனால் முழுவதுமல்ல. இரகசியத்தை அம்பலமாக்கும் பூபதி என்ற மருத்துவரும் இன்னும் சில அடிப்படைக் கருத்துக்களுமே வேறு மொழி கவினத்திலிருந்து இரவல். மற்றெல்லாம் சமுதாய நிலையின் படப்பிடிப்பு.

காலம்----மிகப் பழமையும் புதுமையுமற்ற இடைக்காலம். சிற்றரசர்களும், பாளையக்காரர்களும் நாட்டின் பல பகுதிகளில் தங்களின் ஆதிக்கத்தைச் செலுத்திக்கொண்டிருந்த காலமெனில் மிகப் பொருந்தும். கதையில் வரும் இடங்களும் கற்பனைகளேதான்.

இடைக்காலத்து கற்பனை ஒன்றின் வாயிலாக இந்தக் காலத்துக்குத் தேவையான கருத்துக்களைச் சொல்ல ஆசைப்பட்டேன். அது தான் இது! இதை உங்களிடம் தரும் திராவிடப் பண்ணையார் என் நன்றிக்குரியவர். அதோடு, இந்நாவலெழுத வாய்ப்பும் - ஓய்வு அளித்த அரசியலார் பெரு நன்றிக்குரியவர்கள்.

திருச்சி மத்திய சிறை }
20—11—’53.        }             மு. கருணாநிதி.
